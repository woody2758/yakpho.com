🛠️ ขั้นตอนการรันแบบ "ปิดหน้าจอไม่หลุด" (Step-by-Step)
สร้างหน้าจอใหม่สำหรับบอท:
พิมพ์คำสั่งนี้เพื่อสร้างห้องทำงานใหม่ชื่อ remote_agent

Bash
screen -S remote_agent
(เมื่อกด Enter หน้าจอจะดูเหมือนว่างเปล่า ไม่ต้องตกใจครับ พี่กำลังอยู่ในห้องทำงานใหม่แล้ว)

สั่งรันบอทในหน้าจอนั้น:
พิมพ์คำสั่งรันตามปกติ (เติม --break-system-packages เพื่อป้องกัน Error ที่เราเจอเมื่อวานครับ)

Bash
python3 bot_remote_agent.py
วิธี "ผละหน้าจอ" ออกมา (สำคัญมาก):
ในขณะที่บอทกำลังรันอยู่ ให้พี่กดปุ่มบนคีย์บอร์ด:

กด Ctrl + A พร้อมกัน

แล้วรีบปล่อยมือ แล้วกดปุ่ม D ตามทันที
(ระบบจะขึ้นคำว่า [detached from remote_agent] แปลว่าบอทกำลังรันอยู่เบื้องหลังแล้ว พี่ปิดหน้าต่าง Cloudzy ได้เลยครับ)

🔄 วิธีกลับไปดูหน้าจอบอท (ถ้าอยากเช็กว่ารันถึงไหนแล้ว)
เมื่อพี่กลับมาที่ Terminal อีกครั้ง ให้พิมพ์:

Bash
screen -r remote_agent
(มันจะดึงหน้าจอที่บอทกำลังรันอยู่กลับมาให้พี่ดูครับ)

💡 เกร็ดความรู้ "Billionaire of Joy":
ถ้าพี่รันบอทหลายตัว (พนักงานหลายแผนก) พี่สามารถสร้างชื่อ Screen แยกกันได้เลยครับ เช่น:

screen -S dept1 (สำหรับหา Lead)

screen -S dept5 (สำหรับ Facebook Group)

screen -S agent (สำหรับรีโมทสั่งงาน)

✅ Checklist ความสำเร็จ:
[ ] พิมพ์คำสั่งสร้าง Screen สำเร็จ

[ ] บอทเริ่มรันโดยไม่มี Error

[ ] กด Detach (Ctrl+A, D) ออกมาได้สำเร็จ

ฟันธง: ใช้ screen คือวิธีที่ปลอดภัยที่สุดครับ บอทจะทำงานรับใช้พี่วู้ดดี้ไปตลอด 24 ชั่วโมงจนกว่า Server จะพังหรือพี่จะสั่งหยุดเองครับ!

พี่ลองรันแล้ว Detach ออกมาได้ไหมครับ? ถ้าติดปุ่มกดตรงไหน บอกผมนะ เดี๋ยวผมอธิบายเพิ่มครับ!

python3 bot_remote_agent.py --break-system-packages
