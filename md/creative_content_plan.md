# แผนการพัฒนาระบบ หมวด 2 — Creative & Content 🎨

เอกสารนี้รวบรวมแผนการทำงานและสถาปัตยกรรมสำหรับ **หมวด 2: Creative & Content** ซึ่งเป็นระบบสำหรับจัดการเนื้อหาและการโพสต์อัตโนมัติลงในกลุ่มและเพจต่างๆ ด้วย AI

## เป้าหมายของระบบ
เพื่อให้ Staff (AI) สามารถนำข้อมูล สินค้า หรือบริการ ไปสร้าง Content ที่มีความน่าสนใจ (Creative) และทำการโพสต์ (Content Distribution) ไปยังช่องทางต่างๆ บน Facebook ได้อย่างเป็นธรรมชาติและมีประสิทธิภาพ

## ฟีเจอร์หลักและการเรียงลำดับการพัฒนา

### เฟสที่ 1: โพสต์กลุ่มขายของทั่วโลก (Worldwide FB Groups Auto-Post)
*(จะเริ่มพัฒนาในส่วนนี้เป็นอันดับแรก)*
- **กลุ่มเป้าหมาย:** คนไทยที่เปิดร้านนวดไทย/ร้านสปาไทย หรือคนไทยในต่างประเทศ
- **เนื้อหาภาษาไทย:** ไม่ต้องแปลภาษา เนื่องจากกลุ่มเป้าหมายอ่านภาษาไทยเป็นหลัก
- **Context:** ปรับแต่งเนื้อหา (Prompt ของ AI) ให้เข้ากับบริบทของร้านนวดไทยและร้านสปาไทยในต่างประเทศ
- **Peak Time Optimization:** จัดการ Timezone โดยระบบจะคำนวณเวลาและตั้งเวลาโพสต์ให้ตรงกับเวลาที่คนไทยในประเทศนั้นๆ ออนไลน์มากที่สุด (Peak Time)
- **การจัดการรูปภาพ:** ผู้ใช้สามารถอัปโหลดรูปภาพเตรียมไว้เป็นชุด (หลายรูปตามต้องการ) เพื่อให้ระบบนำไปใช้ประกอบการโพสต์

### กลยุทธ์การสร้างเนื้อหา (Content Strategy ตาม AI Strategy)
ระบบจะทำการสร้างและเตรียมคอนเทนต์ไว้ล่วงหน้า (Content Pool) โดยแบ่งหมวดหมู่ตามสีของกลยุทธ์ (AI Strategy) ที่ตั้งไว้ในหมวด 1 ดังนี้:
- **🟢 Case Green:** สร้างคอนเทนต์ประเภท **"ขายตรง / ฮาร์ดเซลส์"** แนะนำสินค้า บริการ หรือโปรโมชันอย่างชัดเจน
- **🟡 Case Yellow:** สร้างคอนเทนต์ประเภท **"ให้ความรู้ / Value Content"** เน้นสร้างประโยชน์และแฝงการขาย (Soft Selling / ป้ายยา) เล็กน้อย
- **🔴 Case Red:** เน้น **"ปฏิสัมพันธ์ (Engagement)"** เพื่อไปปรากฏตัวและทิ้งแฮชแท็ก `#ยักษ์โพธิ์อโรม่า` โดยบอทจะสุ่มเลือกโพสต์ล่าสุดในกลุ่ม แล้วใช้ AI ช่วยอ่านเนื้อหาโพสต์นั้นเพื่อแต่งคอมเมนต์สั้นๆ แบบ "ตามน้ำ" (เกี่ยวข้องกับโพสต์) อย่างเป็นธรรมชาติ

### เฟสที่ 2: โพสต์กลุ่มขายของทั่วไทย (Thai FB Groups Auto-Post)
- ดึงข้อมูลกลุ่มจาก Database มาแสดงผล
- ดึง Content จากระบบ Content Strategy ด้านบนมาใช้งาน
- มี Spam Protection (สุ่มเนื้อหา, สุ่ม Delay)

### เฟสที่ 3: โพสต์เพจทั่วไทย (Thai FB Pages Auto-Post)
- บริหารจัดการเพจที่บัญชีเป็นแอดมิน
- โพสต์เนื้อหาเชิงลึก/ให้ความรู้ พร้อมแฮชแท็กหลัก เช่น `#ยักษ์โพธิ์อโรม่า`
- มี Content Calendar แสดงตารางงานชัดเจน

## สถาปัตยกรรมระบบ (Architecture & Workflow)

1. **Frontend (UI/UX):**
   - พัฒนาไฟล์ PHP โดยเริ่มจาก `post_world_groups.php` และหน้าจัดการ Content ล่วงหน้า
   - UI สำหรับอัปโหลดรูปภาพเป็นชุด
   - UI สำหรับดูและจัดการ Content ที่สร้างล่วงหน้า (แยกตาม Green, Yellow, Red)
   - UI ควบคุมเวลาโพสต์และการสุ่มเนื้อหา
   
2. **Backend & AI (Logic):**
   - API เชื่อมต่อ OpenAI / Gemini เพื่อ Generate เนื้อหาตาม Prompt (Green, Yellow, Red) เตรียมไว้ใน Database
   - ระบบ Timezone Calculator คำนวณหา Peak Time ของแต่ละประเทศเพื่อจัดลงคิว (Job Queue)

3. **Bot Worker (Execution):**
   - Python Script (Selenium/Playwright) คอยอ่าน Queue และดำเนินการตาม Strategy (โดยเฉพาะ Case Red ที่ต้องอ่านโพสต์ชาวบ้านก่อนคอมเมนต์ตามน้ำ)
   - อัปเดตสถานะกลับมาที่หน้าเว็บ (Player Bar)

## ข้อสรุปจากการตรวจสอบแผน (Finalized Decisions)
- **รูปภาพ:** อัปโหลดเตรียมไว้เป็นชุด (Gallery/Pool) ให้ระบบสุ่มหยิบไปใช้
- **Case Red:** ไม่เจาะจงคีย์เวิร์ด สุ่มโพสต์ล่าสุดในกลุ่ม แล้วใช้ AI คอมเมนต์ตามน้ำแบบสั้นๆ พร้อมทิ้งแฮชแท็ก `#ยักษ์โพธิ์อโรม่า` เพื่อไปปรากฏตัว
